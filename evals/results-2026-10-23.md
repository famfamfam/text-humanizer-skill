# Проверка Humanizer от 23 октября 2026

Исторический отчёт версии 1.0.0. [Актуальные результаты и статус](results-1.1.2.md).

Проверена версия 1.0.0 до переименования. Инструкции скилла после
проверки не изменялись. Изменена методика тестирования: ответ без подтверждённой
загрузки правил больше нельзя засчитать как проверку скилла.

к ошибкам скилла.

## Условия проверки

Использован Codex CLI 0.164.0, модель `gpt-6-astra`, reasoning `xhigh`.
Обновлённый CLI установлен только во временную папку проекта. Глобальная
установка не менялась. Claude Code 2.1.305 остановился на лимите аккаунта.

Для проверки содержимого каждый из 14 запросов запускался в новой сессии.
Во вход полностью передавались `SKILL.md`, `references/russian.md` и
`references/english.md`, затем исходный запрос из [cases.md](cases.md).
Критерии оценки и ожидаемые ответы модели не передавались. Пользовательские
настройки CLI отключались только для этого процесса; файловый доступ оставался
в режиме read-only. Это проверяет выполнение переданных правил, но не установку
и не автоматический выбор скилла.

Ответы оценены по критериям корпуса вручную. Точное сохранение цитаты, URL,
подстановки и отдельных обязательных строк дополнительно проверено скриптом.
Хеши переданных инструкций сверены с файлами проверяемой версии.

## Что обнаружено при проверке загрузки

В штатной конфигурации Codex явный вызов `$humanizer` привёл к успешному чтению
ядра и русских рекомендаций: это подтверждено результатами инструментов с кодом
завершения 0 и содержимым соответствующих файлов. Факты в ответе на запрос 1
сохранены, но модель дописала: «Саму оценку роста не проверял».

Это нарушение требования вернуть только готовый текст. В 11 успешных проверках
с полными инструкциями во входе такой приписки не было. Причина различия пока
не установлена; вывод о том, что интеграция полностью прошла тест, делать нельзя.
После восстановления лимита нужен повтор этого запроса в штатном клиенте.

Отдельная попытка изолировать штатную загрузку с помощью
`--ignore-user-config` заблокировала чтение файлов политикой дочернего процесса.
Модель всё равно выдала внешне корректные ответы. Все эти результаты исключены
из зачёта: качество ответа не доказывает применение скилла. В методику добавлена
обязательная проверка загрузки. Это также означает, что полученный в той попытке
ответ длиной 100 символов не считается успешным тестом № 13.
